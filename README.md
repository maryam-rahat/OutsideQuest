# OutsideQuest
A 70s-arcade-style desktop game that sends you outside on photo missions and has a local AI judge your snap.

Press one button, get a weather-aware mission, go complete it, snap a photo, and watch a vision model react to the real world. Build a daily streak.

## Features

- Missions generated by a local LLM, tuned to your live weather
- Webcam photo judged by a local vision model with a PASS or FAIL and a witty reaction
- Persistent daily streak and best score
- Retro CRT UI: amber and phosphor-green text, Atari-style stripes, typewriter output, blinking `INSERT COIN`
- Resizable window with scaling fonts, fullscreen on `F11`

## Stack

Python, tkinter, OpenCV, Ollama, Open-Meteo

## Requirements

- Python 3.9+
- [Ollama](https://ollama.com) running locally
- A webcam
- Internet access for the weather lookup only

## Setup

```
pip install ollama opencv-python
ollama pull llama3.2
ollama pull llava
python mission.py
```

## Controls

| Input | Action |
|-------|--------|
| NEW MISSION | Fetch weather, generate an objective |
| SNAP PHOTO | Capture a webcam frame and judge it |
| F11 | Toggle fullscreen |
| Esc | Exit fullscreen |

## How it works

1. Launch: the streak loads from disk and the weather sensor scans.
2. NEW MISSION: weather is refreshed, then `llama3.2` generates a one-sentence outdoor photo mission suited to the conditions.
3. SNAP PHOTO: OpenCV grabs a webcam frame and sends it, with the mission and weather, to `llava`.
4. `llava` replies starting with PASS or FAIL plus a one-line reaction.
5. On PASS, the streak updates.

## Streak rules

Stored in `~/.mission_streak.json`.

| Situation | Result |
|-----------|--------|
| First PASS ever | Streak = 1 |
| PASS on the day after your last PASS | Streak + 1 |
| Second PASS on the same day | No change |
| Gap of more than one day | Display shows 0, next PASS restarts at 1 |

`best` updates whenever the streak exceeds it.

## Privacy

- Mission generation and photo judging run locally through Ollama. Your photo never leaves your machine.
- The latest photo is saved to your system temp folder as `mission.jpg` and overwritten on each snap.
- Weather uses two network calls: `ip-api.com` for approximate location from your IP (plain HTTP), then Open-Meteo for conditions. If either fails, the game falls back to `Weather unavailable` and still works.

## Configuration

Edit the constants at the top of `mission.py`.

| Constant | Purpose |
|----------|---------|
| `TEXT_MODEL` | Ollama model for missions |
| `VISION_MODEL` | Ollama model for judging |
| `THEMES` | Mission themes picked at random |
| `FONT` | Monospace font for the UI |
| `STREAK_FILE` | Where the streak is saved |

## Troubleshooting

| Problem | Fix |
|---------|-----|
| `Camera unavailable` | Close other apps using the webcam, or change the index in `cv2.VideoCapture(0)` |
| Connection error on missions | Start Ollama and confirm both models are pulled |
| Slow judging | Use a smaller vision model or run Ollama on a GPU |
| Font looks off | Set `FONT` to a monospace font installed on your system |
| `Weather unavailable` | Check your connection; missions still generate without weather |
